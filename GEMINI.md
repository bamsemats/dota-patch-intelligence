# Project Instructions

## Documentation Strategy
As a core project convention, **documentation must be treated as a living artifact**. 
Whenever a major milestone, phase, or significant architectural change is completed, you MUST automatically update the relevant documentation files (e.g., `ROADMAP.md`, `ARCHITECTURE.md`, `DECISIONS.md`, `DATA_MODEL.md`) to reflect the current state of the project. Do this routinely as part of your "wrap-up" process for any major task before moving on to the next one.

## Styling Constraints
**DO NOT USE Tailwind CSS.** All styling must be done using standard CSS files (e.g., Vanilla CSS or CSS Modules). Rely on explicit class names and external stylesheets rather than utility classes. Use the official Dota 2-inspired color palette where applicable.
