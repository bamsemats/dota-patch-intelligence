# DATA_MODEL.md

## 1. Overview
The Dota Patch Intelligence data model is designed to support deep relational analysis between patches, entities (heroes/items), and their multi-dimensional performance metrics.

## 2. Core Entities

### Patch
Represents a specific Dota 2 game version.
*   `id`: Primary Key
*   `version`: String (e.g., "7.41d")
*   `releaseDate`: DateTime
*   `metaAnalysis`: Link to synthesis narrative.

### Entity
Any identifiable object in the game.
*   `name`: Unique string (e.g., "Anti-Mage")
*   `type`: Enum (HERO, ITEM, NEUTRAL, GENERAL)

### PatchChange
The atomic unit of balance.
*   `patchId`: Link to Patch
*   `entityId`: Link to Entity
*   `subEntityName`: Optional (e.g., "Mana Void")
*   `rawNote`: The literal text from Valve.
*   `classificationType`: Enum (Buff, Nerf, Adjustment, Rework, Unknown)
*   `netScoreDelta`: Float (-10 to +10)
*   `strategicWeight`: JSON object containing rank-specific multipliers.

### FeatureVector
A 7-dimensional representation of a hero's kit balance in a specific patch.
*   `farming`, `mobility`, `survivability`, `teamfight`, `laning`, `siege`, `utility`.

### WinrateSnapshot
Captures a hero's performance during a specific patch era.

| Field | Type | Description |
| :--- | :--- | :--- |
| `patchId` | Int | Link to the Patch |
| `entityId` | Int | Link to the Hero |
| `bracket` | String | "HERALD" through "DIVINE", or "PROFESSIONAL" |
| `winrate` | Float | Percentage (0.0 to 1.0) |
| `matchCount` | Int | Sample size |
| `isHistorical` | Boolean | True if sourced from SQL Professional Baseline |

**Hybrid Logic:**
*   **Current Patch:** Multiple snapshots per hero (one for each rank tier).
*   **Historical Patch:** A single "PROFESSIONAL" snapshot per hero, representing the aggregate high-level baseline.

## 3. Analysis Entities

### MetaAnalysis
A high-level synthesis of a patch's impact generated by Gemini 2.5 Flash.
*   `metaShifts`: Array of thematic game-tempo changes.
*   `synergisticWinners`: Array of objects:
    *   `entity`: Name of Hero/Item.
    *   `synergyExplanation`: Qualitative reasoning.
    *   `temporalAssessment`: Enum (Net Gain, Recovery, N/A).
*   `synergisticLosers`: Array of objects (entity, synergyExplanation).
*   `roleSpecificWinners`: Top 3 winners for each of the 5 roles (includes `temporalAssessment`).
